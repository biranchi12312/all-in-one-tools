# New OrivaStudio v2 — Tool UI Redesign

## Source study
Old v76 tool pages were studied for visible content, terminology, task descriptions, workflow sequence and visual hierarchy.

## Important implementation rule
No old v76 HTML, CSS or JavaScript was copied.

The new v2 tool pages use a new shared tool visual layer designed to align with the redesigned new OrivaStudio homepage.

## Updated pages
Image Tools:
- Compress Images
- Resize Images
- Format Converter
- Crop & Rotate

PDF Tools:
- Images to PDF
- Merge PDF
- Split PDF
- PDF to Images

Also updated:
- All Tools

## Preserved architecture
The existing Phase 7 tool engines and their required data attributes remain in place. This update changes the presentation layer and page copy without replacing the processing engines, safety limits, dialogs, production runtime or service-worker foundation.
