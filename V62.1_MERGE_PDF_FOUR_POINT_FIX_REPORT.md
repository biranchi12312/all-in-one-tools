# OrivaStudio V62.1 — PDF Merger Four-Point Fix

Implemented in V62 without changing the V76 merge logic wholesale:

1. PDF dependency loader now has a 20s timeout, cleanup, and failed-load cache eviction so a transient CDN failure can be retried.
2. PDF Merge now integrates with AuraProcessingManager using operation IDs, with success/error completion and reset. Legacy boolean fallback remains for compatibility.
3. Mobile touch reorder now uses Pointer Events pointer capture on the drag handle for a stable gesture outside the handle bounds.
4. The unused legacy `assets/js/tools/engines/merge-pdf.js` implementation was removed because no active V62 reference points to it; the dedicated runtime is the sole merge implementation.

Cache/version bumps: merge page assets v39 and service-worker cache v62.1.
